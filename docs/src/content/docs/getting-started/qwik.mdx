---

[Devicons](https://github.com/devicons/devicon) as typed Qwik components (ESM only) — 578 icons in `flat`, `high-contrast`, and `modern` sets.

## Install

```sh
pnpm add @devicons-pack/qwik
```

## Usage

```tsx
import {Rocket} from "@devicons-pack/qwik/flat";

<Rocket width={32} />
<Rocket title="Rocket launch" />  // accessible: role img + aria-label
```
